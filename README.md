# Bharat VoteChain 2.0
Varanasi Ward 10 Pilot

Logic: 1 Wallet = 1 Coin = 1 Vote = Fir Hamesha Block

Problem: Double voting aur vote kharidna
Solution: Har voter ko ek wallet, ek hi coin milega, ek baar vote send karne ke baad wallet block ho jayega. Na dubara send, na receive.

Tech: Blockchain + Anonymous Proof + VVPAT
